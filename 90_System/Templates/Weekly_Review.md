# Weekly review {{date:GGGG-[W]WW}}

- [ ] Empty `00_Inbox`: promote, merge or archive every note.
- [ ] Review the flashcard queue up to the daily cap. If a backlog built up, run the "catch up backlog" mode: oldest and weakest first, no new cards until it is under the cap.
- [ ] Write from memory the 3 ideas of the week, then check the notes.
- [ ] Pick next week's single priority and write its if-then plan: "If ..., then I will ...".
- [ ] Missed days are fine. Count the days you studied, not a streak.
