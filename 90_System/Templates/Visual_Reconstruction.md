# Visual reconstruction

Rebuild the diagram, the map or the flow of a concept from memory. Then compare it with the
source and see which relations are missing.

The exercise is for the relations, not for the drawing skill. A diagram that keeps the nodes but
loses an arrow has not kept the idea.

The agent names only what is missing and asks a question about each missing relation. It never
redraws the diagram and never adds the relation for you.

"What I drew" is yours. "Relations kept" is what survived. "Relations missing" is what the
source has and your drawing does not. "Question it left open" is the question the missing
relation raised for you.
