# Memory palace

A palace is a route of familiar places. Each place holds one item. You walk the route in your
mind and say the item at each place, in walking order.

Use a palace for ordered material: sequences, checklists, ordered steps. It does not replace
understanding. The evidence for it is a large effect on immediate serial recall with low
certainty, so it is optional and never the only method.

The agent asks one place at a time, in walking order, and you answer without notes. Each place is
recorded on its own, with the item id `palace-<name>-<place number>`.
