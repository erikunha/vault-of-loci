# Counterfactual

Change one premise of a concept and say what changes because of it. The answer has to be about the
mechanism.

Saying that the recommendation changes is not an answer. The answer says which step of the
mechanism breaks and what follows from that.

| Date | Concept | Premise changed | What changes | Why |
|---|---|---|---|---|
|  |  |  |  |  |

The agent picks the premise, states it, and asks what changes and why. You answer first. The
answer is graded against the source and the rubric. Confidence from 1 to 5 is asked before the
reveal.
