# Compression challenge

Say the same idea three times: in full, as an analogy, and as the shortest version that still holds. A short version that keeps the causal relations and drops the examples is a good compression. A short version that drops a relation is not a summary, it is a different claim.

Write the three versions in your own words. The agent lists the relations that survived and the ones that did not, and you put the missing relation back.
