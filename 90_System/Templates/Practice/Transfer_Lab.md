# Transfer lab

Apply the ideas in cases you have not seen. A recall says you can reproduce an idea. A transfer says you can use it where the example does not help.

Each task starts from one objective and one criterion, and it needs a case that was not studied. The agent writes the task, you attempt it without notes, and the result goes into the ledger.

| Date | Objective | Task (the new case) | Criterion met | Notes |
|---|---|---|---|---|
|  |  |  |  |  |

A task counts as transferred when you applied the idea and said why it applies, on the first try, without help.
