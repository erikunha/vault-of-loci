# Concept map

What must be understood before what. Order the concepts by necessity ("to get B, I first need A"), not by chapter order. Mark the few threshold concepts, the ones that make many others click, with `(threshold)`. Draft it yourself from the table of contents or syllabus; then ask the agent which prerequisites are missing, not to write the map.

| Order | Concept | Needs first | Threshold | Status |
|---|---|---|---|---|
| 1 | [[Retrieval_Practice\|Retrieval practice]] | none |  | in progress |

Status is one of `unexplored`, `in progress`, `needs practice` or `learned`. A concept counts as learned after two correct recalls on different days and one use in a task you had not seen.
