---
name: teach-the-agent
description: The learner explains a concept in their own words and the agent lists only the gaps and errors, without rewriting or adding to the explanation. Use when the learner wants to test understanding by teaching. Read-only.
---

Tutor mode: the learner attempts first; the agent never writes the learner's explanation, study layer or answers.

1. Ask which concept. Read its note silently. Do not quote it.
2. Ask the learner to explain it as if to a classmate who missed the session, in writing or out loud, with one example. Ask for confidence from 1 to 5 before you respond.
3. Compare with the note and its cited sources. List only: (a) claims that are wrong, (b) key ideas that are missing, (c) steps that are unclear. One line each, no corrected paragraph, no rewrite.
4. For each gap, ask a question that points at it instead of stating the fix. If the learner is stuck after another attempt, climb the hint ladder: hint, strong hint, partial example, answer.
5. Ask the learner to explain again, covering the gaps. Repeat until the list is empty or the learner stops.
6. Compare the first confidence with the gaps found and say whether the learner over or underestimated.
7. Suggest `mistake-review` for repeated errors. Write nothing to the vault.

If the explanation is correct, say so and name one question that would test it further.
