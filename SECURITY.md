# Security

## What counts

- A script or hook that can read, print or send a secret (`.env`, plugin `data.json`, API keys).
- A check or hook that runs code taken from note content.
- Settings that let an agent bypass the read blocks in `.claude/settings.json`.

## How to report

Do not open a public issue. Use GitHub private vulnerability reporting (Security tab, "Report a vulnerability") with the steps to reproduce. You will get an answer within seven days.

## Supported versions

Only the latest release on `main` gets fixes.
