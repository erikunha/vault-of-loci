# Semantic Scholar

> [!tldr] In 3 lines
> A paper search site with a developer API page and a reader in beta.
> Use it to check a paper and its neighbourhood before you read it.
> The home page is short. Citation counts and alerts were not on it.

## Study explanation

The home page announces two things. The first is an API for developers, which now includes paper search, better documentation and more stability. The second is Semantic Reader in beta, an augmented reader that makes scientific reading more accessible and richer in context. It is available for selected papers.

The home page does not describe citation counts or filters. For use in this vault: check the citation count, the venue and the date of a paper whose arXiv ID you already have. Peer review, gaps and recency were not verified on this page.

The home page asks for no account and no key to see the news. Whether the API needs a key is not verified, because the documentation page (https://api.semanticscholar.org/api-docs) could not be extracted. Nothing was read from it.

## Key takeaways

- **Remember:** Semantic Scholar is the place to check one paper you already know by its arXiv ID: citations, venue and date.
- **Common confusion:** A home page that announces an API is not a page that documents citation counts. Do not cite features the page did not state.
- **Exercise:** Pick a paper you saved. Open its page here and write down its venue and date without looking at the paper.
